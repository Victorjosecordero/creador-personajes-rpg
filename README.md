# Forja RPG

Creador de fichas de personajes RPG hecho con HTML, CSS y JavaScript sin dependencias.

## Funciones

- Identidad, historia y estadísticas vitales del personaje.
- Reparto de 27 puntos entre seis atributos.
- Habilidades e inventario editables.
- Retratos predeterminados o imagen personalizada.
- Guardado automático en el navegador, exportación JSON e impresión.
- Diseño adaptable para móvil, tablet y escritorio.

## Desarrollo local

Abre `index.html` directamente o sirve la carpeta con cualquier servidor estático.

## Publicación

El sitio está preparado para GitHub Pages y no requiere proceso de compilación.
